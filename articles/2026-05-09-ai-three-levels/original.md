# AI 能力的三个简单层次

我简单把AI应用能力分为三个层次，对应于编程能力的三个阶段。

1）会和大模型交互聊天。简单说就是和ChatGPT聊天，你问一句它答一句，不积累任何工具，输入的命令和回答用完就丢掉。
2）会写一个较长的文件，让Claude Code，或者 Codex 等执行，并且不断调整。比如能够不断修改 SKILL.md 文件通过多次调试形成一个可以被反复使用的文件
3）会在一个文件夹里面（有的时候就是Skills文件夹），组织多子个文件夹目录里面的多个文件，形成一个项目，交给 Claude Code 等定期或者手动执行。这个文件夹里面或许含有几十个 .md 的文件，每个文件描述项目精确控制的一个方面，比如市场活动项目包括 platforms/ 文件夹里面的xiaohongshu.md, facebook.md, x.md, etc)，brain/ 文件夹里面的 voice.md, angels.md, ideas.md, product.md，以及 prompts/ 文件夹里面的 image_gen.md, video_gen.md, text_gen.md 等等。

对应于编程，这三个阶段对应于：
1）会进入交互编程环境，输入一行代码，立刻得到这一行代码的输出（就是所谓的REPL，全称是 Read–Eval–Print Loop，就是在命令行直接输入 "python3" 加回车，不带源文件名的那个界面）。这是一个学习，debug 的环境，但是不可能有什么真正的产出。
2）会把 Python 命令写入一个 hello_world.py 文件，然后会用 "python3 hello_world.py" 执行，看结果。这才可能不断修正不断改进，每一次修整都沉淀下来可复用。
3）会用 "import" 命令，会把自己文件夹里面的其他文件，以及其他库里的文件引用进当前项目，形成大量 .py 文件，以及其他的相关文件组成的一个小型项目，然后用 "python3 index.py" 去执行整个项目。

现在大多数人的迷惑之处在于，只停留在第一层，没有尝试第二层和第三层，而听到别人在做 AI 编程的时候，以为别人是用第一层的方法编程，那就怎么也不理解别人说的是什么了
