# 我的 agent 在我睡觉的时候也在睡觉

Dash 贴出了他 Codex 的月度用量：120 亿 token。

我看了看自己的数字：Claude Code 42 亿，Codex 1.5 亿。上周我和 Claude Code 的对话时间是 49 小时，这一周可能还要高一些。

49 小时。差不多每天 7 小时。

把这几个数字放在一起，一件事就清楚了：我的 42 亿，大部分是**陪跑 token**。我在线，它在跑；我睡觉，它也跟着睡。我的在线时间和 token 消耗之间，有一条接近 1:1 的相关线——这不是好的迹象。

Dash 的 120 亿不可能是靠人工陪跑出来的，那得坐多少小时。更可能的是，他搭了某些 workflow 和 loop，在他不在线的时候它还在跑。

我现在主要在用 skill，还没有搭好这一层。skill 很好——它把你在场时的效率拉高了。但它的天花板是你的时间，因为你不在，它就不跑。

workflow 和 loop 是另一件事。你定义任务，它自己跑，出了问题再叫你。你睡觉，它还在；你出门，它还在。

我给自己设了一个目标：**在场时间从 49 小时降到 30 小时，Claude Code 的工作时间增加到每周 60 小时。**

这两个数字要反向走。搭对了，它们就会解耦。
