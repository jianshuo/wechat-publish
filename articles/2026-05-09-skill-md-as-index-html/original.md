# SKILL.md 相当于 index.html

每一种语言都有一种象征性的常用的入口文件名，比如c语言常用main.c作为入口，python常用的是index.py或者app.py，而HTML的入口常常是index.html。AI时代的编程，入口已经越发明显的成为SKILL.md。我现在的每一个工作，一直是以新开一个skill，不断的尝试，不断要求AI提炼并且更新SKILL.md，再测试，再提炼保存的循环。当我开始用这个循环工作的时候，一种日拱一卒，每天都有进步的感觉才真正出现，这也是AI时代我的AHA时刻。

今天晚上回到家就比较晚了，但是花了几个小时时间把曾经花了一年左右搞的几个功能写了一下，大致效果比那个时候的还要好。
