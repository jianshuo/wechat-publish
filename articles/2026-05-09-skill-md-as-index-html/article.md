# SKILL.md 相当于 index.html

每一种语言都有一种象征性的、常用的入口文件名。

比如 C 语言常用 `main.c` 作为入口，Python 常用的是 `index.py` 或者 `app.py`，而 HTML 的入口常常是 `index.html`。

AI 时代的编程，入口已经越发明显地成为 `SKILL.md`。

我现在的每一个工作，一直是以新开一个 skill，不断地尝试，不断要求 AI 提炼并且更新 `SKILL.md`，再测试，再提炼保存的循环。

当我开始用这个循环工作的时候，一种日拱一卒、每天都有进步的感觉才真正出现，这也是 AI 时代我的 AHA 时刻。

今天晚上回到家就比较晚了，但是花了几个小时时间，把曾经花了一年左右搞的几个功能写了一下，大致效果比那个时候的还要好。

一个是多机位摄像机的，代码在：https://github.com/jianshuo/multicam-skill

一个是翻译视频的 skill：https://github.com/jianshuo/translate-video

一个是微信公众号发布助手：https://github.com/jianshuo/jianshuo-wechat-mp-publish

写 `SKILL.md` 以及相关的文件，或许是新时代程序员的主要工作。
