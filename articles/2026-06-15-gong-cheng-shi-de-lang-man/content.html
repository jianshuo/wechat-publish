工程师的浪漫，从来不是玫瑰。


别人送花，工程师送工具；别人写情书，工程师写代码。这份浪漫不挂在嘴上，全藏在一条条命令、一个个协议里——外人看是冷冰冰的技术，懂的人看一眼，就会心一笑。


用 Claude Code 的时候，我常用一个 macOS 自带的命令，叫 caffeinate，作用是让电脑撑住、别睡着。这名字起得真好：多灌点咖啡因，电脑就不困了，能多陪你熬一会儿。给一台机器灌咖啡——这种拟人的小幽默，就是工程师藏的浪漫。


我最喜欢的是 ping。隔着半个地球，朝一台素未谋面的主机轻轻戳一下，屏住呼吸等它回话。屏幕跳出一行 64 bytes from ...——像冲着黑暗喊了一声，那头真的有人应了。工程师就靠这一行字确认：我和这个世界之间，是通的。


还有我曾经最着迷的 finger。它到今天还占着 79 号端口（鼎鼎大名的 HTTP 占的是 80 号）。对着它敲一句：


finger jianshuo@jianshuo.dev


本该返回 jianshuo.dev 这台主机上、jianshuo 这个用户根目录里的 .plan 文件——你在里面写点什么，别人 finger 一下就看见了。这不就是古早年代的朋友圈吗？只可惜在 HTTP 吞噬一切的路上，如今几乎没有机器还守着 79 号端口了，想起来还有点伤感。


连 DNS 的命名都有讲究。主机地址一直用 A 记录。后来 IPv4 升级到 IPv6，地址从 32 位变成 4 个 32 位，新记录就顺手叫 AAAA——正好四个 A。多一个字母都不浪费，少一个字母也不将就。这种精确的对称，工程师看了心里舒服。


你看，工程师就爱在最不该有感情的地方，偷偷放进感情。


而工程师最大的浪漫，是他造的东西会替他继续干活。


人会累，会走，会忘，代码不会。你写下的那行逻辑，在你睡觉的时候还在跑，在你早忘了它的时候还在跑，在公司换了三拨人之后还在跑。你等于把自己的一小块时间，永远地存了下来。


到了 AI 时代，这份浪漫更进了一步。以前我把重复的事写成脚本，现在我把它讲给他听——我跟 Claude 说一句话，他就帮我写文章、配图、发公众号。我现在写得最多的已经不是代码，是 skill：一段教他怎么帮我做事的说明书。写一个 skill，就像收了一个永不嫌烦、不会忘、不请假的徒弟，我教他一次，他记一辈子。



工程师的浪漫，说到底就一句话：在冷冰冰的世界里，忍不住藏一点温度，造一个东西，让它替我，也替我在乎的人，把日子过得轻一点。


花会谢，脚本不会。
