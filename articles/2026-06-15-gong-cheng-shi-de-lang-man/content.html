用 Claude Code 的时候，我常用一个 macOS 自带的命令，叫 caffeinate，作用是让电脑撑住、别睡着。这名字起得真好：多灌点咖啡因，电脑就不困了，能多陪你熬一会儿。给一台机器灌咖啡——这种拟人的小幽默，就是工程师藏的浪漫。


我最喜欢的是 ping。隔着半个地球，朝一台素未谋面的主机轻轻戳一下，屏住呼吸等它回话。屏幕跳出一行 64 bytes from ...——像冲着黑暗喊了一声，那头真的有人应了。


还有我曾经最着迷的 finger。它到今天还占着 79 号端口（鼎鼎大名的 HTTP 占的是 80 号）。对着它敲一句：


finger jianshuo@jianshuo.dev


本该返回 jianshuo.dev 这台主机上、jianshuo 这个用户根目录里的 .plan 文件——你在里面写点什么，别人 finger 一下就看见了。这不就是古早年代的朋友圈吗？只可惜在 HTTP 吞噬一切的路上，如今几乎没有机器还守着 79 号端口了。


连 DNS 的命名都有讲究。主机地址一直用 A 记录。后来 IPv4 升级到 IPv6，地址从 32 位变成 4 个 32 位，新记录就顺手叫 AAAA——正好四个 A。多一个字母都不浪费，少一个字母也不将就。


最逗的是 HTTP 状态码。200、404、500 大家都认得，可它到今天还留着一个 418，叫「我是一个茶壶」。你要是一本正经地命令一个茶壶去煮咖啡，它就回你：418，我是茶壶，煮不了。这是愚人节玩出来的代码，二十多年过去，各大项目（比如 Node）都舍不得删，最后干脆转正成了正式状态码。有人说得好：


418 提醒我们：计算机底层的那些过程，仍然是人造出来的。


这句话，说穿了工程师所有的浪漫——他们就爱在最不该有感情的地方，偷偷放进感情。
