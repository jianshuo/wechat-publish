# 原始想法（从《AI 炼金术》对话里挑出来的一个点）

任鑫笑着说："我感觉我现在就是帮 AI 打杂的。"
我接："我们不是 AI 的阿姨吗。"

这句玩笑话里其实有个挺真的观察——现在哪怕一个很成熟的程序员去 vibe coding，经常会卡在一些**必须人手动**的步骤上：

- 注册一个新账号、注册一个 token
- 买一个域名
- 付一笔钱（x402 协议还没普及）
- 在某个网页上点一个按钮

Cloud Code 或者 AI 跑着跑着，会向你求救："什么东西都好了，但这一件事必须用你的小手手去点一下，否则我干不了了。"

但是！这种 tension 一旦存在，就会被极快地消解掉。

Cloudflare 前两天就把"注册账号→支付→注册域名→上线"整套自动化了。在他做这件事之前，AI 想上线一个网站，到买域名这一步就必须求人。现在不用了。

每一个"AI 求人"的点，都是一个新的创业机会——而全世界这么多聪明人，只要有那个空隙在，就一定会有人去填。

任鑫的判断：半年到一年内，"AI 向人求助"这种情况基本不会再有。

我们 AI 阿姨这份工作，正在消失。
