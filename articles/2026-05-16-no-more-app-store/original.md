# 原始想法（从《AI 炼金术》对话里挑出来的一个点）

任鑫开玩笑说：「我已经不从 App Store 下载软件了，我都从 Cloud Code 里面下载。」

听着像段子，但仔细想想是真的——

需要剪个视频第 8 秒到 27 秒？以前我得专门下载一个剪辑工具。现在我直接跟 Cloud Code 说一句，它自动剪好给我。

需要把图片压缩成 PPT 高的格式？以前我得装一个压图软件。现在直接说。

任鑫说他们公司一个干了十几年财务的同学，最近也自己写了个小游戏，玩得很开心。

所以"软件"这个东西，作为"功能的载体"——这一层功能在淡化。

简单一点的软件，会**融在大语言模型本身里面**。你不需要再下载它，你直接说你要什么。

大语言模型，承载了原来浏览器扮演的角色——只不过浏览器装的是网页，大语言模型装的是"功能"。

但最底层的 building blocks 还在。AI 怎么剪视频？最终还是用 ffmpeg。大语言模型不会再写一个 ffmpeg。

意思是：未来的"软件"分层——
- 底层：building blocks (ffmpeg, sqlite, openssl, ...) 不变
- 中层：app（功能的载体）正在消失
- 顶层：大语言模型 + 自然语言意图

被吃掉的是"中间那一层"。app 这个东西，正在淡化成可有可无。
