# Mac 上的语音输入神器 HoldSpeak

用 Claude Code 或者 Codex 工作的时候，有一个很多人还没有意识到的重要变化，就是我们不需要跟他说语法完备，没有错别字，简洁清晰的指示，即便是啰嗦一些，有些嗯啊，中间又反复，他都可以接受，这就是让语音输入成为他们最好的搭档。我在使用 Claude Code 的时候，几乎都用 HoldSpeak 来做语音输入，按一下 Fn，然后就意识流一样跟他说话，结束了，再按一下 Fn，一堆指示就直接给到了 Claude Code，无论里面有多么语无伦次，Claude Code 都可一照单全收，并且给出合理的结果。如果说有两件事情一旦用上就回不去了，一个是Claude Code本身，一个就是 HoldSpeak 语音输入。

https://holdspeak.com （直接用Mac打开然后下载安装就可以了）
