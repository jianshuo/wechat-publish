# 原始思路（对话中共同形成）

核心：数学。

- 一个 50% 涨、50% 跌的公平市场，硬币不偏不向，长期期望为零。
- 人性两条出厂设置：好小便宜、吃不得小亏。
- 落到买卖上：赚时见好就收（涨 10% 就跑），亏时死扛不认（扛到 -30%）。赢一小口，亏一大口。
- 算账：100 块，10 轮，5 涨 5 跌（最可能路径）→ 100 × 1.1⁵ × 0.7⁵ = 27。亏掉近四分之三。
- 把 10 轮所有组合都算一遍：亏本概率 94.5%。要涨到 8 次以上才可能不亏，只有约 5% 机会。
- 是谁把公平游戏变成九成五要输的游戏？是"赢一小口、亏一大口"这个习惯，把每轮期望从 0 拧成 -10%（0.5×+10% + 0.5×-30% = -10%）。
- 更扎心：真实股市是缓慢上涨的，相当于市场往你这边吹了顺风，你还是能亏——顺风顶不过每轮 -10% 的自我消耗。
- 题眼：不是市场跟你作对，是你身上那点"赢怕飞、亏不认"的人性在跟你作对，市场只是如实算给你看。
- 救法：别问"我赚了还是亏了"，只问"如果今天手里是现金，这个我还会不会买"。
